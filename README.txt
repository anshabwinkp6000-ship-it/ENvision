Bramayugam (2024) — fan tribute website (static HTML/CSS/Bootstrap)
====================================================================

Files:
  index.html  — the whole site (Home, Film, Cast, Music, Awards,
                Trailer sections + quote + footer)
  style.css   — all site styling (theme + classes)
  script.js   — simple vanilla JS (navbar glass-on-scroll,
                close mobile menu after a link is tapped)
  bootstrap/  — local Bootstrap 5.3.3 CSS and JavaScript files
  images/     — bramayugam-hero.jpg, bramayugam-portrait.jpg

Bootstrap 5.3.3 is included locally. The Google fonts (Cormorant
Garamond, Jost) are loaded online; without internet, the site uses
its included serif and system-font fallbacks.

To view: open index.html in any browser. To host: upload the
folder as-is to any static host (Netlify, GitHub Pages, etc.).

You can swap the placeholder images in images/ with real posters,
stills and cast photos — keep the same file names and the layout
stays intact.

Fan-made tribute. Not affiliated with the filmmakers or rights holders.
